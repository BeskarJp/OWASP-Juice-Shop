## Proof of Concept (PoC)

#### 1. Enumeration & Techniques

* **Techniques used :** OSINT, Password Strength.
* **Tools used :** GRC Haystack

#### 2. Reproduction Steps

**Step 1 : Contextual Analysis**

The challenge requires logging in as Amy. Based on the Futurama theme recurring throughout the Juice Shop, it's established that Amy Wong is in a relationship with Kif Kroker.

**Step 2 : Find the first word for password**

The challenge indicates a very precise resistance time: `93.83 billion billion billion centuries`. This time value is generated by the GRC Haystack. By entering the `K1f` base chain, we can measure the growth in complexity.

**Step 3 : Connecting the "One Important Final Note**

The challenge mentions a `Final Note that Amy ignored`. Within the Juice Shop's internal lore, this note explicitly warns employees : `Do not fill the end of your passwords with dots to reach the length requirement`.

**Step 4 : Reconstructing the Credentials**

Using the GRC Haystack tool, I reconstructed the password by following Amy's logic :

```text
Start with "K1f", then add the points one by one until the brute-force search time exactly matches the index duration.
```

The duration of 93.83 billion trillion trillion centuries is reached when the password length hits exactly 24 characters. As a result of : `K1f.....................`.

**Step 5 : Final Exploitation**

Login as amy `amy@juice-sh.op` with the password `K1f.....................`. It's done !


## Risk Assessment

* **Business Impact :** Unauthorized access allows for Identity Theft. An attacker can steal personal data, view order history, and exploit saved payment methods.

* **Technical Description of the Impact :** This demonstrates False Security. Even though the password is long, its entropy (randomness) is very low. A long password is easy to crack if it follows a predictable pattern like repeating dots.

---

## Actions & Remediation

#### Mitigation Strategies

   - Block passwords that use too many repeating characters.

   - Use tools to score passwords based on complexity and patterns rather than just length.

#### Recommended Fixes

   - Multi-Factor Authentication prevents a login even if the attacker guesses the password.

   - Explain to users doing that weak password with symbols does not make it secure.
